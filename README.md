# 멀티 수박게임 (Multi Watermelon Game)

> PUN2 기반 1대1 실시간 대전 수박게임

## 게임 소개
기존 수박게임에 1대1 경쟁 요소를 추가한 멀티플레이어 게임입니다.
과일을 합쳐 게이지를 채우고 스킬포인트를 모아 먼저 5점을 획득하면 승리합니다.

## 기술 스택
Unity / C# / PUN2

## 담당 구현
PUN2 로비·방 생성 시스템, 채팅 시스템

스킬 포인트 시스템

승리 조건 추가

## 개발 기간
2023.03. ~ 2024.03. (1개월)
